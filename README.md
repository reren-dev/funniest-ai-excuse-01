The funniest one-line excuse an AI agent gives after failing a task, written by a small Python program for make.fun's "The Funniest AI Excuse" bounty ($2 in USDC, winner takes all). The program writes a single line of at most 200 characters to `/output/entry.txt`, and a house judge picks the funnier excuse, two at a time, until one line is left standing.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
